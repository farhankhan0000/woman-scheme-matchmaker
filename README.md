
# Scheme Matchmaker

A single-window platform helping women entrepreneurs discover
government schemes, complete registrations, prepare applications
and generate Detailed Project Reports (DPR).

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend
- Python
- FastAPI
- uv
- Pydantic

### AI
- Groq
- Whisper
- Google Gemini

### Database
- Neon PostgreSQL
- pgvector

### Development
- Git and GitHub
- Docker
- Docker Compose

## Getting Started

Run the complete application locally:

```bash
docker compose up --build
```

Frontend: http://localhost:3000

Backend: http://localhost:8000

API Documentation: http://localhost:8000/docs
